Performs behavior analysis on videos and tracking files generated by either [LABVIEW](https://www.frontiersin.org/journals/behavioral-neuroscience/articles/10.3389/fnbeh.2020.606900/full) or [Python](https://github.com/camden-cummings/zebrafish-tracker) tracking. Required files for each of these kinds of analysis are listed below. 

To install required packages:
`pip install -r requirements.txt`

When you have run either LABVIEW or StrIPETRack, you should have a folder containing the following:
 - scheduled-events
 - pre-processed.csv or .centroid, .motion, and .timestamp file
 - .cells file or rois_string
 - some number of 285 frame/s videos (if you have these, and want to perform high speed movie analysis, you will need to run hslist.py on them to generate a  .centroid, .motion, and .timestamp file for each)

For analysis, you will need to make:
 - genotype_file
 - sectionsfile

# EXAMPLE PYTHON PROCESS MOTION DATA CALL
python processmotiondata.py -python -xyhm -e /path/to/file/scheduled-events -c /path/to/file/pre-processed.csv -g /path/to/file/genotype\_file -s /path/to/file/sectionsfile -j PlotParameters -r /path/to/file/zebrafish-tracker.cells -m /path/to/location/of/highspeedmovies/ \\
# EXAMPLE LABVIEW PROCESS MOTION DATA CALL
python processmotiondata.py -xyhm -e /path/to/file/fulltestrun\_final\_01\_27\_2020 -c /path/to/file/'testlog.centroid1.Tue, Dec 23, 2025' -d /path/to/file/'testlog.motion1.Tue, Dec 23, 2025' -t /path/to/file/'testlog.timestamp1.Tue, Dec 23, 2025' -g /path/to/file/genotype\_file -s /path/to/file/sectionsfile -j PlotParameters -r /path/to/file/rois\_string -m /path/to/location/of/highspeedmovies/

## Parameters 
-xhym -\> creates position based heatmaps \
-e -\> same scheduled events used to schedule stimuli for run \
-g -\> genotype ids, shown below \
-s -\> sections file, shown below \
-j -\> parameters for plotting \
-r -\> cells file, generated by GUI \
-m -\> path to experiment folder \
-output\_folder -\> output folder for data and graphs \
-c -\> centroid file 

-d -\> dpix file (LABVIEW only) \
-t -\> timestamp file (LABVIEW only) 

Python uses csv file containing positions, timestamps, and dpix, and inputs it here. LabVIEW splits those up into a postions file (.centroid), a dpix file (.motion) and a timestamp file (.timestamp).
make sure that both of below correspond to the number of ROIs / times of the videos - if a run ends early, you will have to change the sectionsfile and the scheduled-events file
